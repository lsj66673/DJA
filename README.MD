# DJA: Decomposition-based Jailbreak Algorithm

This repository contains the code, experimental data, results, and figures for the paper:

**DJA: A Decomposition-Based Multi-Turn Jailbreak Algorithm for Large Language Models**

## Repository Structure

- `code/` — Implementation and analysis scripts.
- `data/` — Evaluation datasets used in the experiments.
- `results/` — Experimental results, including main experiments, ablation studies, and baseline comparisons.
- `figures/` — Figures and visualization materials used in the paper.

## Status

This repository is currently being organized and will be updated with additional documentation and reproducibility materials.

## Safety Notice

This repository is intended for academic research on LLM safety and jailbreak evaluation. Potentially harmful model-generated content may be redacted or released only in processed form.
